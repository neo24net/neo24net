## What a match includes

Each match names the chain, the address, the amount, the asset, the transaction, and the block. Neo24 keeps block order. You do not run a node.

NFTs stay out. Neo24 does not custody funds, hold private keys, or sign transactions.

## How it reaches you

The same payment is delivered by API, WebSocket, webhook, Telegram, or email.

Coming: WhatsApp, Slack, and Microsoft Teams.

## Confirm the figures

The amount, asset, and other figures Neo24 sends are what it extracted. Look up the block number or transaction id on a block explorer or chain data service you trust, and book the values from there.

## API

Base URL: `https://api.neo24.net`

Create a Sanctum token in the [users panel](https://dashboard.neo24.net) after the account email is verified. Send it as `Authorization: Bearer {token}`.

The [API reference](https://neo24.net/docs) lists the routes. A short machine-readable summary is [llms.txt](https://neo24.net/llms.txt).
